# Calculatrice en C 🧮

Un programme simple et interactif écrit en C en ligne de commande qui permet d'effectuer des opérations mathématiques de base entre deux nombres entiers.

## 🚀 Fonctionnalités

Le programme prend en charge les opérations mathématiques suivantes :
- **Addition** (`+`)
- **Soustraction** (`-`)
- **Multiplication** (`*`)
- **Division** (`/`)
- **Modulo** (`%`) - *Reste de la division euclidienne*

## 🛠️ Prérequis

Pour compiler et exécuter ce projet, vous aurez besoin d'un compilateur C installé sur votre machine, tel que **GCC**.

## ⚙️ Compilation et Exécution

1. Ouvrez votre terminal.
2. Naviguez jusqu'au dossier contenant votre fichier source (par exemple `main.c`).
3. Compilez le code avec la commande suivante :
   ```bash
   gcc main.c -o calculatrice
